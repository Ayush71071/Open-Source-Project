## ⚙️ Scripts Included

This repo contains 5 scripts (inspired by the assignment requirements):

### 1. System Identity Report

Gives basic system info like user, OS, and kernel version.
👉 Helps understand the environment before running programs.

### 2. Python Package Checker

Checks whether a Python package (like numpy) is installed or not.
👉 Useful for dependency checking.

### 3. File Permission Auditor

Looks at file permissions and tells you who can access what.
👉 Important for security basics.

### 4. Log File Analyzer

Scans a log file and finds error lines.
👉 Helps in debugging and monitoring.

### 5. Manifesto Generator

Takes user input and creates a simple “open-source manifesto” text file.
👉 Just a fun way to show automation + file handling.
